# kmworks website

The kmworks ecosystem site and documentation hub, served at <https://kmworks.date>.

Built with [Nimbus](https://nimbus-docs.com) (Astro). The landing pages live in `src/pages/`; docs live at `/server/` (kmrs) and `/reader/` (kmreader), authored as MDX in `src/content/docs/`.

Agent-facing outputs (per-page markdown, `/llms.txt`, `/llms-full.txt`, JSON-LD, sitemap) are generated by Nimbus on every build. See `AGENT.md` for the project conventions when editing this site with a coding agent.

## Develop

```sh
npm install
npm run dev        # dev server with hot reload
npm run build      # production build in dist/
npm run typecheck
npm run lint:docs  # prose + MDX lint
```

## Deploy

Cloudflare Workers Builds: pushes to `main` build the site (`npm ci && npm run build`) and deploy the `kmworks` Worker (static assets from `dist/` + the `kmworks.date` / `www.kmworks.date` custom domains from `wrangler.jsonc`). To deploy a local build manually:

```sh
npm run deploy     # wrangler deploy
```
