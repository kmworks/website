KMReader is a native Komga client for iOS, macOS, and tvOS.

## 1. Download

Get KMReader on the [App Store](https://apps.apple.com/app/id6755198424). It requires iOS 17.0, macOS 14.0, or tvOS 17.0.

## 2. Add your Komga server

On first launch, add a server with its address, for example `https://komga.example.com`. You can save multiple servers and switch between them later. Server management lives in the Server area; on iPhone, it is part of Settings.

## 3. Sign in

Sign in with your Komga username and password, or with an API key. Keys can be created and managed in the app.

:::note
Any Komga 1.20.0+ server works, including [KMServer](/server/), the single-binary Rust server from the same family.
:::

## 4. Start reading

Tap a book to open it directly. For its detail page, reading options, download controls, or Peek, open the book's context menu instead: long-press it on iOS or right-click it on macOS.

On iPhone, open Settings with the gear on the Dashboard. On iPad and tvOS, use the Settings tab or sidebar entry. On macOS, use the KMReader menu → Settings.
